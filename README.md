# 🌸 Detalles Michu — Tienda en línea de flores artesanales

Sitio web de **Detalles Michu**, emprendimiento de flores y ramos hechos a mano con listón y limpiapipas.

🌐 **Demo en vivo:** https://alan-alavez.github.io/detalles-michu/

## ✨ Funcionalidades
- **Catálogo** de flores individuales y ramos con precios.
- **Ficha de producto** con selector de color y cantidad.
- **Personalizador de ramos**: elige flores, colores, cantidad y envoltura con vista previa en SVG que se actualiza en tiempo real.
- **Carrito lateral** que se guarda en el navegador (`localStorage`).
- **Proceso de compra en 4 pasos**: carrito → datos y entrega → pago → confirmación, con validación de formularios.
- **Pedido por WhatsApp** con el resumen generado automáticamente.
- Galería, preguntas frecuentes, nosotros y políticas de privacidad.
- Diseño **responsivo** para celular, tablet y escritorio.

## 🛠️ Tecnologías
HTML5 · CSS3 · JavaScript (vanilla) · SVG · localStorage · GitHub Pages

## 📁 Estructura
```
├── index.html          Inicio
├── nosotros.html       Historia, misión, visión y valores
├── catalogo.html       Flores y ramos
├── personaliza.html    Personalizador de ramos
├── galeria.html        Ramos entregados
├── preguntas.html      Preguntas frecuentes
├── privacidad.html     Políticas de privacidad
├── css/styles.css
├── js/app.js           Lógica de la tienda (catálogo, carrito, pago)
└── img/                Logo y fotografías
```

## ▶️ Ejecutar localmente
Abre `index.html` en el navegador o usa la extensión **Live Server** de VS Code.

> El pago con tarjeta está en **modo demostración** (no realiza cobros).
